# SLog · 航海日志（DailyNote）

把半年一张的生活格子从 Excel 换成可以在电脑和手机上写的网页。按天记主笔记、颜色、P3、地点、照片，支持周 / 月 / 半年视图。

## 本地运行

需要 Node 22。

```bash
npm install
npm run dev
```

浏览器打开提示的地址（默认 `http://localhost:8080`）。没配数据库时会用内嵌的临时库，适合试用；关掉进程后预览数据可能清空。

访客试用走 `/try`，不写数据库。登录后的日记按账号存在 Postgres。

## 部署

代码按 Vercel + Neon Postgres 来写。部署时需要：

- `DATABASE_URL`：Neon 连接串
- 登录相关环境变量（Better Auth / Grok 部署时会注入）

不要把密钥写进仓库。项目里没有 `.env` 文件。

## 说明

照片目前压缩后存在数据库里，免费档数据库（大约 0.5 GB）会被照片占满。大量原图以后适合改成对象存储。
